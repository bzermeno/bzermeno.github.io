## About

This portfolio showcases three software enhancement projects that demonstrate growth across the core competencies of the Computer Science program: software engineering and design, algorithms and data structures, and databases. Each project was originally developed during earlier coursework and later enhanced to reflect professional-level skills in code quality, performance, and security.

---

## Projects

### Software Engineering and Design — CS-320
A Java-based Service Management System implementing three independent service modules (ContactService, TaskService, and AppointmentService) with full CRUD operations, strict input validation, and comprehensive JUnit unit tests. The enhancement focused on applying object-oriented design principles, modular architecture, and secure coding practices.

### Algorithms and Data Structures — CS-300
A C++ course planner that reads course data from a CSV file, stores it in a sorted vector, and provides an interactive menu for listing all courses or searching for a specific course by number. The enhancement improved algorithmic efficiency, input handling, and code maintainability through a dedicated `CourseManager` class.

### Databases — CS-340
A Python MongoDB CRUD module for an Animal Shelter (AAC) database. The enhancement added compound indexes for query performance, MongoDB aggregation pipelines (`$match`, `$group`, `$sort`) for adoption trend analysis, and scalable database-side analytics to support larger datasets without increasing application overhead.
